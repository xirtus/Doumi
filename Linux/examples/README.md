# Linux Examples

These rules are starter templates for the Rust/Linux edition of Doumi.

Copy a rule into your user config directory, review the paths, then enable it from the CLI or GUI.

```bash
mkdir -p "$HOME/.config/doumi/rules"
cp rules/archive_downloads.json "$HOME/.config/doumi/rules/"
```

Included examples:

- `rules/archive_downloads.json`
- `rules/cleanup_temp.json`
- `rules/compress_large_files.json`
- `rules/organize_photos.json`
- `rules/sort_documents.json`
