# Doumi FreeBSD Port

This directory contains the FreeBSD port files for Doumi.

## Files

- `Makefile` — FreeBSD port Makefile
- `pkg-descr` — Package description
- `pkg-plist` — Package file listing
- `pkg-message` — Post-install message shown to users
- `doumid` — rc.d service script
- `doumi.desktop` — Desktop entry file

## Usage

### Build and install from port

```bash
# Copy to ports tree
cp -r packaging/freebsd /usr/ports/sysutils/doumi
cd /usr/ports/sysutils/doumi
make install clean
```

### Quick local install

```bash
./install-bsd.sh
```

### rc.d service

```bash
# Start the daemon
service doumid start

# Enable auto-start at boot
sysrc doumid_enable=YES

# Optional settings
sysrc doumid_dry_run=YES    # Preview mode - no files changed
sysrc doumid_debug=YES      # Verbose logging
```

### Dependencies

Required packages (install with `pkg`):
- `rust` — Rust compiler
- `gtk4` — GTK4 runtime (for GUI)
- `libadwaita` — Adwaita widgets (for GUI)
- `pkgconf` — Build configuration
- `bash` — Build scripts
- `dbus` — Desktop notifications
- `sqlite3` — Action logging database

## Porting to Other BSDs

The codebase is largely BSD-ready.  To port to NetBSD or OpenBSD:

1. The `xattr` crate supports FreeBSD (via extattr syscalls). For NetBSD
   and OpenBSD, the tag action falls back to a `.doumi_tags.json` sidecar
   file.
2. File watching uses the `notify` crate which selects `kqueue` automatically
   on all BSD platforms.
3. Copy the rc.d script and adapt it to your init system (rc.d on NetBSD,
   rc.d or rc.local on OpenBSD, etc.).
4. Install GTK4 and libadwaita from pkgsrc/ports.
